## 关于 UDP「订阅」

**不需要向源端发送订阅请求。** UDP 是单向推送：

1. 你在本机绑定监听端口（默认 `12730`）
2. PLC 或三台转发服务器把数据发到你的 `IP:端口`
3. 程序被动接收并解析

界面里的「来源 IP 过滤」只是用来区分三台服务器的数据，不是订阅握手。

## 快速开始

### Python 版
```bash
cd python
pip install -r requirements.txt
python3 monitor.py
# 浏览器打开 http://localhost:8080
```
默认已开启 **Mock 模拟数据**，无需真实 UDP 即可看到 2 Hz 动态图表。

### TypeScript 版
```bash
cd typescript
npm install
npm run dev
# 前端 http://localhost:5173
```

### Mock 发送器（联调前自测）
```bash
# Python 版
python3 python/mock_sender.py --host 127.0.0.1 --port 12730 --hz 2

# 同时发到三台服务器
python3 python/mock_sender.py --targets 10.172.241.102:12730 10.172.241.103:12730 10.172.237.32:12730
```

## 功能概览

- 解析附件中的 `UDP_ClientSend` 结构（SMH/OICR 位信号 + MH/MT/MC/CNTRH 位置 + 心跳）
- 5 分钟滚动缓存，Chart.js 实时曲线
- 2 Hz 刷新频率
- 可配置本机监听端口、来源 IP 过滤
- Mock 模式开关（调试前即可演示）
- Tailwind CSS 深色界面

## 接真实数据时

1. 取消勾选「Mock 模拟数据」
2. 确认本机监听端口为 `12730`（或你指定的端口）
3. 让发送方把数据发到你的机器 IP
4. 可选：点预设按钮设置来源 IP 过滤，区分三台服务器

若 ping 不通 `10.172.241.x`，可添加路由：
```bash
sudo ip route add 10.172.241.0/24 via 10.172.237.254
```
